# BNB Greenfield 快速开始指南

> 5分钟快速完成 Greenfield 存储设置和测试

## 🚀 概述

本指南为开发者提供快速配置和测试 BNB Greenfield 存储的步骤。基于端到端（E2E）测试框架，可以在几分钟内完成完整的 Greenfield 存储工作流程验证。

## 🎯 核心特性

### ✅ 自动化流程
- **CreateObject → PutObject**: 一个 `put()` 调用完成整个工作流
- **无手动 txn_hash**: 系统自动获取事务哈希
- **错误处理**: 完整的异常处理和重试逻辑
- **性能监控**: 上传/下载速度测量

### 🌐 完整的中文支持
- **中文输出**: 所有测试结果和错误信息都是中文
- **中文文档**: 从设置到部署的完整中文指南
- **配置模板**: 中文的配置文件示例

## 📋 快速开始步骤

### 1. 配置环境（5分钟）

创建 `.env` 文件：

```bash
# 复制 E2E 测试配置模板
cp docs/ref/agent0-py/.env.e2e.示例 .env

# 编辑配置（必须字段）
nano .env
```

**必需环境变量：**
```bash
GREENFIELD_BUCKET=hubble-reputation-test
GREENFIELD_PRIVATE_KEY=your_private_key_here
```

### 2. 获取测试资源（5分钟）

1. **获取测试网 BNB**
   - 访问：https://gnfd-bsc-testnet-faucet.bnbchain.org/
   - 连接钱包并请求测试网 BNB

2. **创建测试存储桶**
   - 访问：https://dcellar.io/（测试网模式）
   - 创建存储桶：名称同上一步配置
   - 设置可访问权限

3. **导出私钥**
   - MetaMask → 设置 → 安全与隐私 → 显示私钥
   - 复制私钥（不包含 0x 前缀）

### 3. 运行测试（5分钟）

```bash
# 运行完整测试套件
uv run python run_greenfield_e2e.py all

# 运行单个测试
uv run python run_greenfield_e2e.py small  # 小文本测试
```
